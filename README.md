# Pawstop prototype

A mobile-first concept prototype for dog-friendly road-trip stop planning.

## What this V1 tests
- Origin/destination + dog preferences
- A curated Jersey City → Chicago Pawstop itinerary
- Dog-specific match presentation
- The core "My dog needs a stop" interaction

This is intentionally a prototype: the route recommendations are curated rather than generated from a live routing/data engine.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example `pawstop`).
2. Upload the files in this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.

## Next validation step
Put the live prototype in front of 10–20 people who road-trip with dogs. Ask them to use it without explaining it first, then capture what they expected to happen and whether they would use it on a real trip.
