# Pawstop V1.1

Changes:
- Named real-world stops replace generic placeholders.
- Working Google Maps navigation handoff.
- Interactive Fastest / Largest green space / Restrooms alternatives.
- Confidence and provenance/source links.
- Expandable “Why this stop?” details.

Prototype limitation: drive times and detours are illustrative, not live-routed. Dynamic conditions such as dog traffic, grass condition, waste, mud, and closures still need live/community data. Pawstop does not assess medical safety.

Deploy by replacing the four files in the existing GitHub Pages repo root and committing the changes.
